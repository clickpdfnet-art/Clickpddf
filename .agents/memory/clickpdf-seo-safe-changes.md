For ClickPDF, consult the installed BeyondSEO skill when it is relevant to SEO audits or SEO-affecting site changes. Preserve unrelated site behavior and avoid changing routes, canonical URLs, hreflang, sitemap, or PDF processing unless the task requires it.

**Why:** The user added the BeyondSEO skill and asked that it be used where useful to avoid harming the site's SEO.

**How to apply:** Read the skill before SEO audits, content optimization, or changes likely to affect crawlability, metadata, structured data, or indexing. Keep localization-only changes separate from SEO configuration.
