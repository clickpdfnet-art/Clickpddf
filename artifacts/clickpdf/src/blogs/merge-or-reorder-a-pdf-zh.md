# 合并 PDF 还是重新排列页面？选择合适的工具

不确定应该合并 PDF 还是调整页面顺序？要看内容目前存在哪里。如果文档分别保存在多个 PDF 文件中，就合并这些文件。如果页面已经在同一个 PDF 中，只是顺序不对，就整理该文件。

![对比将多个独立 PDF 合并成一个文档与重新排列单个 PDF 页面缩略图。](/blog-assets/merge-or-reorder/merge-vs-page-order.jpg)

## 有多个文档时合并独立 PDF

如果每个部分都是单独的文件，例如封面、报告和参考资料分别保存为三个 PDF，请使用 PDF 合并工具。按所需的显示顺序添加文件，生成合并文件，并在分享前检查。

ClickPDF 的 [Merge PDF 工具](/tools/merge-pdf/)可以合并独立的 PDF 文件。请先查看接收方的要求：有些平台要求分别上传文件，或规定特定顺序。

## 已有一个 PDF 时重新排列页面

如果你已有一个 PDF，需要移动、旋转或删除其中的页面，请使用页面整理工具。ClickPDF 的 [Organize PDF 工具](/tools/organize-pdf/)提供页面重排、旋转和删除功能。完成后检查文档，确认更改正确。

## 两项操作都需要时

如果要把多个 PDF 合并成一个文件，同时还要调整部分页面的顺序，请先合并独立文件。然后在页面整理工具中打开合并后的 PDF，调整最终页面顺序。这样可以更方便地整体检查文档。

## 简单的三步流程

1. **判断问题。** 多个独立文件需要合并；单个文件中的页面需要整理。
2. **选择对应工具。** 多个文件使用 Merge PDF，调整单页使用 Organize PDF。
3. **检查结果。** 打开文件，查看首页和末页，确认顺序，并确保没有遗漏必要内容。

学生合并作业文件的示例，请参阅[大学作业 PDF 合并指南](/blog/daxue-zuoye-hebing-pdf-zh/)。

## 常见问题

### 合并 PDF 和整理 PDF 有什么区别？

合并会把多个独立的 PDF 文件组合成一个文档。整理则会更改已有 PDF 中页面的顺序或方向。

### 调整页面顺序前要先合并文件吗？

如果页面分散在不同的 PDF 文件中，请先合并文件，然后检查合并后文档的页面顺序，并按需调整。

### 可以在不同 PDF 之间移动页面吗？

先使用合并工具将独立 PDF 放在一起，再把生成的 PDF 放入页面整理工具中调整顺序。

### 整理 PDF 时可以旋转或删除页面吗？

ClickPDF 的 Organize PDF 页面提供页面重排、旋转和删除功能。只进行需要的更改，并在完成后检查结果。

### 重新排列页面会降低 PDF 质量吗？

重新排列与压缩不同。结果可能取决于源 PDF 和所用工具，因此请打开最终文件，检查文字、图片和交互元素。
