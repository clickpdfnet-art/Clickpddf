Saat menyiapkan tugas kuliah, halaman sampul, isi tugas, referensi, dan lampiran mungkin tersimpan sebagai beberapa file PDF. Jika pengajar meminta semuanya dalam satu PDF, Anda dapat menggabungkan file menjadi satu dokumen. Selalu ikuti petunjuk mata kuliah terlebih dahulu, terutama jika file harus diunggah secara terpisah.

## Jawaban singkat

Biasanya, letakkan sampul terlebih dahulu, lalu isi tugas, referensi, dan lampiran yang diwajibkan. Gabungkan file dalam urutan tersebut, kemudian buka PDF akhir untuk memastikan semua halaman lengkap dan terbaca. Petunjuk pengajar tetap menjadi prioritas.

## Mengapa PDF tugas perlu digabungkan?

Menggabungkan PDF membuat pengumpulan lebih rapi dan memudahkan Anda mengunggah satu dokumen lengkap jika kampus atau pengajar memintanya. Sampul, tugas, referensi, dan lampiran juga tetap berada dalam satu file.

Baca petunjuk tugas terlebih dahulu. Sebagian pengajar meminta unggahan terpisah, nama file tertentu, atau urutan khusus untuk referensi dan lampiran. Jangan berasumsi bahwa satu format cocok untuk semua mata kuliah.

## Langkah 1: Kumpulkan dan periksa file PDF

Cari semua file yang diperlukan, misalnya:

- `Sampul.pdf`
- `Tugas.pdf`
- `Referensi.pdf`
- `Lampiran.pdf`

Buka setiap file dan pastikan halaman yang benar ada di dalamnya. Jangan ubah file asli sebelum salinan gabungan selesai diperiksa.

Jika halaman tulisan tangan tersimpan sebagai foto, ubah foto tersebut menjadi PDF terlebih dahulu dengan [panduan mengubah foto tugas tulisan tangan menjadi PDF](/blog/gabungkan-foto-tugas-tulisan-tangan-ke-pdf-id/). Pastikan halaman terbaca dan arahnya benar sebelum ditambahkan.

Jika PDF tidak dapat dibuka seperti biasa atau meminta kata sandi, tanyakan kepada pengirim file atau pengajar sebelum memasukkannya.

## Langkah 2: Susun file dalam urutan yang benar

Urutan yang umum digunakan:

1. Halaman sampul
2. Isi tugas utama
3. Referensi atau daftar pustaka
4. Lampiran, jika diperlukan

![Sampul, tugas, referensi, dan lampiran dalam urutan pengumpulan yang umum.](/blog-assets/college-assignment/clickpdf-assignment-document-order-4x3.jpg)

Petunjuk pengajar lebih penting daripada urutan yang disarankan ini.

## Langkah 3: Gabungkan PDF

Buka [alat Gabungkan PDF ClickPDF](/tools/merge-pdf/). Tambahkan file dan susun sesuai urutan yang benar. File akan tampil dalam daftar bernomor. Seret file dari pegangannya untuk memindahkan posisi, atau gunakan kontrol urutan alfabetis dan terbalik jika hasilnya sesuai kebutuhan.

Periksa pilihan file agar tidak ada bagian wajib yang tertinggal atau dokumen yang tidak berkaitan ikut masuk. Setelah urutannya benar, mulai penggabungan dan unduh PDF hasilnya. Alat menyatukan file sesuai urutan yang ditampilkan dan tidak mengganti file asli.

## Langkah 4: Periksa PDF akhir

Buka dokumen hasil penggabungan dan periksa:

- Halaman berada dalam urutan yang benar.
- Semua halaman yang diwajibkan sudah ada.
- Teks, diagram, dan tulisan tangan dapat dibaca.
- Tidak ada halaman yang terputar atau terpotong tanpa sengaja.
- Nama file jelas dan sesuai untuk mata kuliah.

Simpan file asli sampai Anda memastikan PDF akhir sudah benar dan unggahan diterima.

## Bagaimana jika PDF terlalu besar?

Menggabungkan file membuat satu dokumen, tetapi ukurannya belum tentu menjadi lebih kecil. Jika PDF gabungan melebihi batas kampus, periksa persyaratan ukuran dan format, lalu pertimbangkan [alat Kompres PDF ClickPDF](/tools/compress-pdf/). Anda juga dapat membaca [panduan mengecilkan ukuran PDF tugas](/blog/cara-mengurangi-ukuran-file-pdf-tugas/).

Setelah dikompres, buka kembali file dan pastikan teks, gambar, serta halaman tulisan tangan tetap terbaca. Jika mata kuliah menerima file terpisah, ikuti petunjuk tersebut daripada menggabungkan atau mengompres file tanpa perlu.

## Daftar periksa sebelum dikumpulkan

Sebelum mengirim tugas, pastikan:

- [ ] Mata kuliah mengizinkan bagian tugas digabungkan dalam satu PDF.
- [ ] Sampul dan bagian lainnya berada dalam urutan yang benar.
- [ ] Semua halaman ada dan terbaca.
- [ ] Referensi dan lampiran disertakan jika diwajibkan.
- [ ] Nama file jelas dan sesuai.
- [ ] File memenuhi batas ukuran dan format platform pembelajaran.

![PDF akhir diperiksa untuk urutan halaman, keterbacaan, bagian wajib, dan ukuran file.](/blog-assets/college-assignment/clickpdf-assignment-final-review-4x3.jpg)

## Pertanyaan umum

### Bagaimana cara menggabungkan PDF untuk tugas?

Gunakan alat penggabung PDF, tambahkan berkas yang diperlukan, susun dalam urutan yang benar, lalu buat satu PDF. Buka hasilnya untuk memastikan semua halaman lengkap dan terbaca sebelum dikumpulkan.

### Apakah halaman sampul harus berada di urutan pertama?

Biasanya sampul diletakkan sebelum isi tugas. Ikuti petunjuk pengajar jika mereka menentukan urutan atau format pengumpulan yang berbeda.

### Apakah referensi dan lampiran perlu disertakan?

Sertakan referensi dan lampiran jika tugas memerlukannya. Periksa petunjuk untuk mengetahui posisi bagian tersebut dan apakah ada materi yang harus diunggah terpisah.

### Bisakah foto tugas digabungkan dengan PDF?

Bisa. Ubah foto menjadi PDF terlebih dahulu, lalu periksa keterbacaan dan arah halamannya. Setelah itu, gabungkan PDF tersebut dengan berkas lain. Lihat [panduan mengubah foto tugas tulisan tangan menjadi PDF](/blog/gabungkan-foto-tugas-tulisan-tangan-ke-pdf-id/).

### Bagaimana jika PDF gabungan melebihi batas ukuran sistem pembelajaran?

Periksa batas ukuran berkas kampus dan pertimbangkan untuk mengompres PDF dengan [alat Kompres PDF ClickPDF](/tools/compress-pdf/). Buka kembali hasil kompresi untuk memastikan teks, diagram, dan halaman tulisan tangan tetap terbaca.
