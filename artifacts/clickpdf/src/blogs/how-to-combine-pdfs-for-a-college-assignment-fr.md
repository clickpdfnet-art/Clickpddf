Pour un devoir universitaire, la page de garde, le devoir principal, les références et les annexes peuvent être enregistrés dans plusieurs fichiers PDF. Si votre enseignant demande un seul PDF, vous pouvez les réunir dans un document. Suivez d’abord les consignes du cours, surtout si les fichiers doivent être déposés séparément.

## Réponse rapide

Dans la plupart des cas, placez d’abord la page de garde, puis le devoir, les références et les annexes demandées. Fusionnez les fichiers dans cet ordre et ouvrez le PDF final pour vérifier que toutes les pages sont présentes et lisibles. Les consignes de votre enseignant restent prioritaires.

## Pourquoi fusionner des PDF pour un devoir ?

Réunir les PDF du devoir facilite le dépôt d’un document complet lorsque votre établissement ou votre enseignant le demande. Cela permet aussi de garder ensemble la page de garde, le devoir, les références et les annexes.

Lisez d’abord les consignes. Certains enseignants exigent des dépôts séparés, un nom de fichier précis ou un ordre particulier pour les références et les annexes. Ne partez pas du principe qu’un seul format convient à tous les cours.

## Étape 1 : rassemblez et vérifiez vos PDF

Repérez tous les fichiers nécessaires, par exemple :

- `Page-de-garde.pdf`
- `Devoir.pdf`
- `References.pdf`
- `Annexes.pdf`

Ouvrez chaque fichier et vérifiez qu’il contient les bonnes pages. Gardez les originaux intacts jusqu’à ce que vous ayez contrôlé le document fusionné.

Si des pages manuscrites sont enregistrées sous forme de photos, convertissez-les d’abord en PDF avec le [guide pour convertir des photos de devoir manuscrites en PDF](/blog/fusionner-photos-devoirs-manuscrits-pdf-fr/). Vérifiez leur lisibilité et leur orientation avant de les ajouter.

Si un PDF ne s’ouvre pas ou demande un mot de passe, demandez conseil à la personne qui vous l’a transmis ou à votre enseignant avant de l’inclure.

## Étape 2 : classez les fichiers dans le bon ordre

Un ordre courant est :

1. Page de garde
2. Devoir principal
3. Références ou bibliographie
4. Annexes, si nécessaire

![Page de garde, devoir, références et annexes classés dans l’ordre habituel de remise.](/blog-assets/college-assignment/clickpdf-assignment-document-order-4x3.jpg)

Les consignes de votre enseignant priment sur cet ordre suggéré.

## Étape 3 : fusionnez les PDF

Ouvrez l’[outil de fusion PDF de ClickPDF](/tools/merge-pdf/). Ajoutez les fichiers et placez-les dans le bon ordre. Ils apparaissent dans une liste numérotée. Faites glisser un fichier par sa poignée pour le déplacer, ou utilisez les commandes de tri alphabétique et d’ordre inverse si elles donnent le résultat souhaité.

Vérifiez la sélection pour ne pas oublier une partie obligatoire ni ajouter un document sans rapport. Lorsque l’ordre est correct, lancez la fusion et téléchargez le PDF obtenu. L’outil assemble les fichiers selon la séquence affichée et ne remplace pas les originaux.

## Étape 4 : vérifiez le PDF final

Ouvrez le document obtenu et contrôlez les points suivants :

- Les pages sont dans le bon ordre.
- Toutes les pages demandées sont présentes.
- Le texte, les schémas et les notes manuscrites sont lisibles.
- Aucune page n’est tournée ou coupée par erreur.
- Le nom du fichier est clair et adapté au cours.

Gardez les originaux jusqu’à ce que vous ayez confirmé que le PDF final est correct et que votre dépôt a été accepté.

## Que faire si le PDF est trop volumineux ?

La fusion réunit les fichiers, mais ne réduit pas nécessairement leur taille. Si le PDF dépasse la limite de votre établissement, vérifiez les exigences de taille et de format, puis envisagez d’utiliser l’[outil Compresser PDF de ClickPDF](/tools/compress-pdf/). Vous pouvez aussi consulter le [guide pour réduire la taille d’un PDF de devoir](/blog/reduire-taille-fichier-pdf-devoir-fr/).

Après la compression, ouvrez de nouveau le fichier pour vérifier que le texte, les images et les pages manuscrites restent lisibles. Si le cours autorise plusieurs fichiers, suivez ses consignes au lieu de fusionner ou de compresser inutilement.

## Vérification rapide avant le dépôt

Avant de remettre le devoir, confirmez que :

- [ ] Le cours autorise le regroupement des parties dans un seul PDF.
- [ ] La page de garde et les autres parties sont dans le bon ordre.
- [ ] Toutes les pages sont présentes et lisibles.
- [ ] Les références et annexes demandées sont incluses.
- [ ] Le nom du fichier est clair et adapté.
- [ ] Le fichier respecte les limites de taille et de format de la plateforme.

## Questions fréquentes

### Comment réunir des PDF pour un devoir ?

Utilisez un outil de fusion PDF, ajoutez les fichiers nécessaires, classez-les dans le bon ordre et créez un seul document. Ouvrez le PDF obtenu pour vérifier que toutes les pages sont présentes et lisibles avant de le rendre.

### La page de garde doit-elle être en premier ?

En général, la page de garde précède le devoir principal. Suivez les consignes de votre enseignant si elles imposent un autre ordre ou un format de remise particulier.

### Dois-je inclure les références et les annexes ?

Ajoutez les références et les annexes si le devoir les demande. Consultez les consignes pour savoir où les placer et si certains éléments doivent être remis séparément.

### Puis-je réunir un PDF avec des photos de devoir ?

Oui. Convertissez d’abord les photos en PDF et vérifiez que les pages sont lisibles et correctement orientées. Fusionnez ensuite ce PDF avec les autres fichiers. Consultez le [guide pour convertir des photos de devoir manuscrites en PDF](/blog/fusionner-photos-devoirs-manuscrits-pdf-fr/).

### Que faire si le PDF fusionné dépasse la limite de taille de la plateforme d’apprentissage ?

Vérifiez la limite de votre établissement et envisagez de compresser le PDF avec l’[outil Compresser PDF de ClickPDF](/tools/compress-pdf/). Ouvrez le fichier compressé pour vérifier que le texte, les schémas et les pages manuscrites restent lisibles.
