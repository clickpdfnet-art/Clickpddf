대학 과제를 준비하다 보면 표지, 과제 본문, 참고문헌, 부록이 각각 다른 PDF 파일로 저장되어 있을 수 있습니다. 담당 교원이 모든 자료를 하나의 PDF로 제출하라고 하면 파일을 하나의 문서로 합칠 수 있습니다. 특히 파일을 각각 올리라고 한 경우에는 먼저 수업 지침을 따르세요.

## 간단한 답변

대부분의 경우 표지를 먼저 두고 과제 본문, 참고문헌, 필요한 부록을 뒤에 배치합니다. 이 순서대로 파일을 합친 다음 최종 PDF를 열어 모든 페이지가 포함되어 있고 읽기 쉬운지 확인하세요. 담당 교원의 지침이 우선입니다.

## 과제 PDF를 합치는 이유

과제 PDF를 합치면 제출 자료를 정돈할 수 있고 학교나 담당 교원이 하나의 완성된 문서를 요구할 때 업로드하기 쉽습니다. 표지, 과제, 참고문헌, 부록도 한 파일에 함께 보관됩니다.

먼저 과제 안내를 읽으세요. 일부 교원은 파일을 따로 제출하거나 특정 파일 이름을 사용하거나 참고문헌과 부록을 정해진 순서로 배치하도록 요구합니다. 모든 수업에 같은 형식이 적용된다고 가정하지 마세요.

## 1단계: PDF 파일을 모으고 확인하기

필요한 파일을 찾으세요. 예를 들면 다음과 같습니다.

- `표지.pdf`
- `과제.pdf`
- `참고문헌.pdf`
- `부록.pdf`

각 파일을 열어 올바른 페이지가 들어 있는지 확인하세요. 합친 사본을 확인할 때까지 원본 파일은 변경하지 마세요.

손글씨 페이지를 사진으로 저장했다면 [손글씨 과제 사진을 PDF로 변환하는 안내](/blog/merge-handwritten-assignment-photos-to-pdf-ko/)에 따라 먼저 PDF로 만드세요. 추가하기 전에 페이지가 선명하고 방향이 맞는지 확인하세요.

PDF가 열리지 않거나 비밀번호를 요구하면 포함하기 전에 파일을 보낸 사람이나 담당 교원에게 문의하세요.

## 2단계: 파일을 올바른 순서로 정렬하기

일반적인 순서는 다음과 같습니다.

1. 표지
2. 과제 본문
3. 참고문헌 또는 인용 목록
4. 필요한 경우 부록

![표지, 과제, 참고문헌과 부록을 일반적인 제출 순서로 정리한 모습.](/blog-assets/college-assignment/clickpdf-assignment-document-order-4x3.jpg)

이 권장 순서보다 담당 교원의 안내가 우선입니다.

## 3단계: PDF 합치기

[ClickPDF PDF 병합 도구](/tools/merge-pdf/)를 여세요. PDF 파일을 추가하고 올바른 순서로 정렬하세요. 파일은 번호가 붙은 목록에 표시됩니다. 핸들을 잡아 끌어 위치를 바꾸거나 결과가 요구한 순서와 맞으면 알파벳순 또는 역순 정렬 기능을 사용하세요.

필수 부분을 빠뜨리거나 관련 없는 문서를 넣지 않도록 선택한 파일을 확인하세요. 순서가 맞으면 병합을 시작하고 결과 PDF를 다운로드하세요. 도구는 표시된 순서대로 파일을 이어 붙이며 원본 파일을 대체하지 않습니다.

## 4단계: 최종 PDF 확인하기

결과 문서를 열고 다음 사항을 확인하세요.

- 페이지 순서가 올바릅니다.
- 필요한 페이지가 모두 들어 있습니다.
- 텍스트, 도표, 손글씨 내용이 읽기 쉽습니다.
- 페이지가 잘못 회전되거나 잘리지 않았습니다.
- 파일 이름이 분명하고 수업 제출에 적절합니다.

최종 PDF가 정확하고 제출이 접수되었는지 확인할 때까지 원본 파일을 보관하세요.

## PDF가 너무 큰 경우

파일을 합치면 하나의 문서가 되지만 파일 크기가 반드시 줄어드는 것은 아닙니다. 학교의 제한을 넘으면 허용되는 크기와 형식을 확인하고 [ClickPDF PDF 압축 도구](/tools/compress-pdf/)를 사용해 보세요. [과제 PDF 파일 크기를 줄이는 안내](/blog/pdf-gwaje-파일-크기-줄이기-ko/)도 참고할 수 있습니다.

압축한 뒤 파일을 다시 열어 텍스트, 이미지, 손글씨 페이지가 여전히 선명한지 확인하세요. 수업에서 여러 파일 제출을 허용한다면 불필요하게 합치거나 압축하지 말고 안내에 따르세요.

## 제출 전 빠른 확인 목록

과제를 제출하기 전에 확인하세요.

- [ ] 수업에서 필요한 부분을 하나의 PDF로 합쳐도 됩니다.
- [ ] 표지와 나머지 부분의 순서가 올바릅니다.
- [ ] 모든 페이지가 포함되어 있고 읽기 쉽습니다.
- [ ] 필요한 참고문헌과 부록이 들어 있습니다.
- [ ] 파일 이름이 분명하고 적절합니다.
- [ ] 파일이 학습 플랫폼의 크기 및 형식 제한을 충족합니다.

## 자주 묻는 질문

### 과제용 PDF 파일은 어떻게 합치나요?

PDF 병합 도구에 필요한 파일을 추가하고 올바른 순서로 정렬한 뒤 하나의 PDF를 만드세요. 제출 전에 결과 파일을 열어 모든 페이지가 들어 있고 읽기 쉬운지 확인하세요.

### 표지를 첫 페이지에 두어야 하나요?

보통 표지는 과제 본문 앞에 둡니다. 담당 교원이 다른 순서나 제출 형식을 안내했다면 그 지침을 따르세요.

### 참고문헌과 부록을 포함해야 하나요?

과제에서 요구하는 경우 참고문헌과 부록을 포함하세요. 어디에 배치해야 하는지, 별도로 제출할 자료가 있는지 안내를 확인하세요.

### 과제 사진을 PDF와 합칠 수 있나요?

네. 먼저 사진을 PDF로 변환하고 페이지가 선명하고 올바른 방향인지 확인한 다음 다른 파일과 합치세요. [손글씨 과제 사진을 PDF로 바꾸는 안내](/blog/merge-handwritten-assignment-photos-to-pdf-ko/)도 참고할 수 있습니다.

### 합친 PDF가 학습 관리 시스템의 파일 크기 제한을 넘으면 어떻게 하나요?

학교의 파일 크기 제한을 확인하고 [ClickPDF PDF 압축 도구](/tools/compress-pdf/) 사용을 고려하세요. 압축한 파일을 다시 열어 텍스트, 도표, 손글씨 페이지가 선명한지 확인하세요.
