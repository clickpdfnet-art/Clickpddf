## 2. Pagkakaiba ng JPG, PNG, at WebP

Makakatulong ang pag-unawa sa mga format para pumili ng angkop na settings. Tumatanggap ang **Image to PDF** ng JPG/JPEG, PNG, at WebP.

### JPG / JPEG

Karaniwang format ito ng digital camera at smartphone photos. Pinapaliit ng lossy compression ang file sa pamamagitan ng pagtatanggal ng ilang pagkakaiba sa kulay.

* **Angkop para sa:** mga litrato ng resibo, scanned na kontrata, property photos, at makukulay na product catalog.
* **Bakit gawing PDF:** Mas madaling isaayos at ibahagi ang maraming phone photo kapag pinagsama sa isang PDF.

### PNG

Lossless raster format ang PNG at sumusuporta ito sa transparency. Pinananatili nito ang naka-save na pixel values, pero hindi nito maibabalik ang detalyeng malabo o wala na sa orihinal.

* **Angkop para sa:** software screenshot, UI mockup, logo, diagram, chart, at scan na malinaw ang text.
* **Bakit gawing PDF:** Maaaring pagsamahin ang ilang PNG screenshot bilang multi-page na dokumento, software guide, o handout.

### WebP

Modernong format ang WebP na maaaring gumamit ng lossy o lossless compression; nag-iiba ang resulta depende sa image at encoding settings. Madalas `.webp` ang extension ng larawang galing sa modernong website.

* **Angkop para sa:** web research archive, digital invoice, online infographic, at marketing asset.
* **Bakit gawing PDF:** Hindi sinusuportahan ng ilang lumang programa ang WebP. Maaaring mas madaling ibahagi ang PDF sa mga gumagamit ng karaniwang PDF viewer; tingnan pa rin ang resulta sa target device.

## 3. Bakit pagsamahin ang images sa PDF

Maraming organisasyon ang mas gusto o nangangailangan ng PDF para sa submission at records. Suriin pa rin ang eksaktong requirement ng tatanggap.

### A. Mas pare-parehong pagbabahagi at pag-print

Nakadepende sa photo viewer, monitor calibration, at operating system ng tatanggap ang hitsura ng image. Itinatala ng PDF ang page dimensions at lokasyon ng content, kaya maaaring maging mas pare-pareho ang pagtingin sa iba't ibang device. Posible pa rin ang kaunting pagkakaiba dahil sa viewer, printer, fonts, at display settings.

### B. Panatilihin ang pagkakasunod ng pahina

Kung kukuha ka ng larawan sa walong pahinang kontrata at ipapadala nang magkakahiwalay, maaaring magulo ang order. Suriin muna ang sequence; susundin ng PDF ang napili mong pagkakasunod.

### C. Bawasan ang abala sa ZIP folder

Maaaring mas madaling i-preview ang multi-page PDF kaysa ZIP archive. May sariling file type at size requirements ang email at submission portals, kaya tingnan ang mga ito bago magpadala.

### D. Mas mahuhulaang pag-print

Maaaring magresulta sa di-inaasahang scaling o margins ang direktang pag-print mula sa browser o photo app. Sa PDF, mapipili ang page size at image placement; suriin ang dokumento at printer settings bago mag-print.

### E. Seguridad at metadata ng dokumento

Karaniwang walang PDF-style password protection o metadata fields ang standalone JPG, PNG, at WebP files. Gumagawa ang Protect PDF ng hiwalay na ClickPDF encrypted package gamit ang AES-256-GCM, hindi standard password-encrypted PDF; gamitin ang katugmang Unlock PDF para ibalik ang orihinal. Kayang baguhin ng Edit PDF Metadata ang mga suportadong PDF property.

## 8. Ano ang gagawin pagkatapos gumawa ng PDF

Maaaring unang hakbang lang ang paggawa ng PDF. Depende sa kasalukuyang tools sa **clickpdf.net**, maaari mo itong ayusin, lagyan ng watermark, o i-compress sa browser.

### A. Paliitin ang image PDF gamit ang Compress PDF

Maaaring lumaki ang PDF mula sa high-resolution na larawan at lumampas sa email o portal limit. Subukan ang available na compression settings. Nakadepende ang laki ng mababawas sa content at settings; maaaring bumaba ang kalidad sa mas malakas na image compression, kaya ihambing ang output.

### B. Pagsamahin, hatiin, at ayusin ang pahina

* **Merge PDF:** Pagsamahin ang maraming PDF sa gusto mong pagkakasunod.
* **Split PDF:** Ihiwalay ang mga pahina o piniling page range sa magkakahiwalay na PDF.
* **Organize Pages:** Tingnan, ayusin, pagpalitin, o burahin ang mga pahina.
* **Rotate PDF:** I-rotate pakanan o pakaliwa ang isang pahina o buong dokumento.

### C. Idagdag ang huling detalye sa Edit & Sign

Magdagdag ng page number, nakikitang watermark, o larawan ng lagda. Hindi nito awtomatikong pinapatunayan ang dokumento o ginagarantiya ang legal na pagtanggap.

* **Page Numbers:** Maglagay ng numero at piliin ang lokasyon.
* **Watermark PDF:** Magdagdag ng text o image at ayusin ang posisyon, laki, anggulo, at opacity. Hindi encryption o tamper-proof protection ang watermark.
* **Sign PDF:** Gumuhit, mag-type, o mag-upload ng larawan ng lagda sa browser. Nakadepende sa tatanggap at naaangkop na tuntunin kung tatanggapin ito.
* **Edit PDF Metadata:** Tingnan o baguhin ang suportadong Author, Title, Subject, Keywords, Creator, at Producer properties.

### D. Hiwalay na encrypted-file option ng ClickPDF

Pumili ng sharing method na tugma sa security requirement mo. Gumagawa ang Protect PDF ng hiwalay na encrypted package; tiyaking magagamit ng tatanggap ang katugmang decryption workflow bago ito ipadala.

* **Protect PDF:** Ini-encrypt sa browser ang PDF data gamit ang Web Crypto AES-256-GCM at inilalagay ito sa sariling format ng ClickPDF. Hindi ito standard password-encrypted PDF; gamitin ang ClickPDF Unlock PDF o standalone vault para ibalik ang orihinal.
* **Unlock PDF:** I-decrypt sa browser ang ClickPDF package gamit ang tamang password. Itago ito nang ligtas; hindi na ito mare-recover kapag nawala.
